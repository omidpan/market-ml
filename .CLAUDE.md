# Quantitative Stock Prediction ML Project

## Project Context
Multi-layered ML model system for real-time 1-minute stock direction prediction using high-frequency Interactive Brokers data.

## System Architecture & Layers
1. Feature Engineering: Transforms 1-min raw bars into custom quantitative indicators.
2. Model Layer 1: Predicts 30-minute macro market direction.
3. Model Layer 2: Narrows down to 15-min, 5-min, and 1-min micro candle direction.

## Operational Constraints & Guardrails
- NEVER directly modify files in `data/raw/` or alter historical data frames.
- NEVER execute destructive terminal commands or unapproved gcloud cloud mutations.
- Always use **Plan Mode** first to outline architectural script changes.
- Feature Engineering Rules: Prioritize manual feature control (ACD, RSI, MACD, ATR metrics). Filter out overnight market noise.
- Model Selection Bias: For binary classification of market direction, group 'hold' signals with 'buy' to optimize directional prediction accuracy.

## Standard Execution Commands
- Feature Generation: `python src/features/build_features.py`
- Local MLflow Tracking: `docker-compose up -d mlflow`
- Colab Sync Checklist: Verify credentials before running cloud notebooks.
