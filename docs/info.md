## install with pip most important libs in venu python version 12
Scikit-learn (Traditional ML: regressions, clustering, random forests):
`pip install scikit-learn and pip install seaborn and pip install pandas`

## PyTorch (Deep learning & neural networks) or TensorFlow (Deep learning & neural networks)
` pip install torch torchvision `
` pip install tensorflow `

## XGBoost (Gradient boosting for tabular data):
`pip install xgboost`
